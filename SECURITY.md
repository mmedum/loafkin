# Security policy

## Reporting a vulnerability

Report it privately, through GitHub's
[security advisory form](https://github.com/mmedum/loafkin/security/advisories/new)
on this repository. Do not open a public issue.

Include what an attacker could do, how to reproduce it, and the release
or commit. Never include a real person's data, an email address, a
session cookie or a token; a synthetic reproduction is enough.

## Supported version

Only the latest release receives fixes, and each release is a deploy
([D-38](docs/architecture.md#decisions)).

## Response

We acknowledge a report within **7 days**.

[`docs/security.md`](docs/security.md) is the threat model. It says what
counts as a vulnerability here and what does not.
